# @webship-js/openproject-steps

Cucumber step definitions for OpenProject, the open-source project management software, a pack for
[webship-js](https://github.com/webship/webship-js) (Playwright and Cucumber): signing in, the work package list and
one work package, its status, comments and time logged, a new work package, and the backlog and sprints.

The steps, their documentation and CI come with the first release, `2.0.0`.
